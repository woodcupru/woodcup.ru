# WOODcup

Одностраничный архивный сайт для закрытого проекта WOODcup / BERЁZKA.

## Структура

- `index.html` — семантическая разметка лендинга
- `styles/main.scss` — исходные стили
- `styles/main.css` — скомпилированные стили для браузера
- `scripts/main.js` — JavaScript страницы
- `assets/images/` — изображения, используемые в лендинге
- `layout/` — исходные макеты экранов
- `CNAME` — домен GitHub Pages

## Дерево на последнем слайде

`assets/tree.svg` — один непрерывный путь: сначала ствол и силуэт, затем штриховка. Рисование запускается заново при каждом открытии последнего слайда. При включённом уменьшении движения в системе дерево отображается сразу.

Настройки находятся в `.scene--origin` в `styles/main.scss`:

- `--tree-color: #fffdf8` — цвет линии (например, `#17130f` для тёмного варианта).
- `--tree-height: 40%` — высота относительно слайда.
- `--tree-draw-duration: 2.2s` — длительность рисования.

После изменения настроек выполните `npm run build:css`.

## Архив

Папка `archive/` хранит:

- бэкап старой версии сайта
- референсы и макеты

`archive/` исключена из git-деплоя рабочей страницы и не используется текущим `index.html`.

## Публикация

Сайт рассчитан на GitHub Pages. Готовый CSS уже лежит в `styles/main.css`, поэтому сборка для публикации не нужна. Для изменения SCSS используйте `npm run build:css`.
